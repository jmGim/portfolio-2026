01 문제 코드

SocketClient::socketReadDataSlotC++
void SocketClient::socketReadDataSlot()
{
    QByteArray byteRecvData;
    QString strRecvData;
    if(pQTcpSocket->bytesAvailable() > BLOCK_SIZE)
        return;                                   // (1) 읽지 않고 반환
    byteRecvData = pQTcpSocket->read(BLOCK_SIZE);
    strRecvData = QString::fromLocal8Bit(byteRecvData);
    emit socketRecvDataSig(strRecvData);          // (2) read 결과 = 메시지 1개
}

증상 가설 (재현 전)

명령이 나뉘어 도착하면 파싱 실패, 한꺼번에 도착하면 뒤 명령이 무시되고, 1024바이트를 넘으면 수신이 멈출 수 있습니다. 실제 재현은 3절의 시험으로 확인합니다.

02 원인 분석

  1. 메시지 경계 없음 — TCP read 한 번에는 메시지 일부 또는 여러 개가 들어올 수 있습니다. 현재는 결과 전체를 하나로 파싱하고 마지막 문자 1개를 제거합니다.
  2. 버퍼 정체 — bytesAvailable() > 1024면 읽지 않고 반환합니다. 버퍼가 줄지 않으면 이후 readyRead에서도 계속 같은 분기를 탈 수 있습니다.
  3. 필드 검증 부재 — strList[2], strList[3] 접근 전에 필드 수를 확인하지 않습니다.
  4. 연결 상태 표시 — 버튼 문구가 connected 시그널이 아니라 IP 입력 확인에 따라 바뀝니다.

03 줄바꿈 프레임 분리 (제안)

누적 버퍼에 쌓고, 줄바꿈까지 온 완전한 프레임만 꺼내며, 남은 조각은 유지합니다. 최대 프레임 길이를 넘으면 연결을 정리합니다.

누적 버퍼 기반 수신C++
void SocketClient::onReadyRead()
{
    m_buf.append(pQTcpSocket->readAll());

    while (true) {
        int nl = m_buf.indexOf('\n');
        if (nl < 0) break;                         // 불완전 프레임은 보관
        QByteArray frame = m_buf.left(nl).trimmed();
        m_buf.remove(0, nl + 1);
        if (!frame.isEmpty())
            emit socketRecvDataSig(QString::fromUtf8(frame));
    }
    if (m_buf.size() > kMaxFrame) {                // 줄바꿈 없는 폭주 입력 방어
        m_buf.clear();
        pQTcpSocket->disconnectFromHost();
    }
}

// 파서: 필드 수 검사 후 접근
QStringList f = msg.split('@');
if (f.size() < 4) return;                      // [ID] @ CMD @ 값 → 최소 4필드 확인
if (f[2] == "LED") {
    bool ok; int led = f[3].toInt(&ok, 16);
    if (ok && led >= 0 && led <= 255) emit ledWriteSig(led);
}

04 SQLite 저장 문제

관찰위험제안
SensorManKJMM 생성자에서 drop table sensor_tb재시작마다 이력 삭제CREATE TABLE IF NOT EXISTS, 스키마 버전 관리
date 단일 primary key, 초 단위 문자열같은 초 입력 시 insert 실패row ID + 밀리초 시각 + 장치 ID
SQL 문자열 연결따옴표 포함 값으로 쿼리 파손prepare/bindValue
기간 조회 ORDER BY 없음, 경계 <=/< 혼재표·차트 순서·경계 불일치정렬·경계 규칙 통일
두 프로그램이 같은 aiot.db, 다른 컬럼스키마 충돌DB 경로·버전 분리
prepared query 예시C++
QSqlQuery q;
q.prepare("INSERT INTO sensor_tb(device, ts_ms, illu, temp, humi) "
          "VALUES(:d, :t, :i, :tp, :h)");
q.bindValue(":d",  deviceId);
q.bindValue(":t",  QDateTime::currentMSecsSinceEpoch());
q.bindValue(":i",  illu);
q.bindValue(":tp", temp);
q.bindValue(":h",  humi);
if (!q.exec()) qWarning() << q.lastError().text();
