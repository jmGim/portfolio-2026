왜 위험한가

Qt의 QWidget은 메인(GUI) 스레드에서만 접근해야 합니다. 작업 스레드의 setPixmap() 호출은 미정의 동작이며, 증상이 간헐적이라 디버깅이 어렵습니다.

03 영상 처리 결함

① 프레임 차이: 포화 연산과 누적 카운트

abs(securityFrame - frame)는 8비트 포화 뺄셈이라 음수 방향 변화가 0으로 사라집니다. 또한 pixelCnt를 비교마다 초기화하지 않아 “한 번에 10%”라는 설명과 달리 작은 변화가 누적될 수 있습니다.

absdiff + 비교별 카운트C++
cv::Mat diff;
cv::absdiff(securityFrame, frame, diff);
std::vector<cv::Mat> ch;
cv::split(diff, ch);
cv::Mat mask = (ch[0] > 30) & (ch[1] > 30) & (ch[2] > 30);
int pixelCnt = cv::countNonZero(mask);        // 비교마다 새로 계산
bool intruder = pixelCnt >= frame.total() / 10;

② HSV 색상 분류

중앙 64×64 ROI의 Hue 평균만 사용하므로 어둡거나 무채색인 영역에서 Hue가 의미 없어 오분류할 수 있습니다. 최소 채도·밝기 기준을 두고 조건별 오분류율을 측정해야 합니다.

용어 정리

이 기능은 학습 기반 인식이 아니라 HSV 임계값·프레임 변화 임계값 기반 규칙 분류입니다. “AI 침입자 식별”로 부르지 않습니다.

04 개선 설계 (제안 · 미적용)

signal 기반 프레임 전달 + 안전한 종료C++
class WebCamThread : public QThread {
    Q_OBJECT
public:
    void requestStop() { m_stop = true; }
    void setMode(int m) { m_mode = m; }
signals:
    void frameReady(const QImage &img);        // 복사본 전달
    void cameraError(const QString &msg);
    void socketSendDataSig(const QString &msg);
protected:
    void run() override {
        cv::VideoCapture cap(0);
        if (!cap.isOpened()) { emit cameraError("open failed"); return; }
        cv::Mat frame;
        while (!m_stop) {
            if (!cap.read(frame) || frame.empty()) continue;
            cv::cvtColor(frame, rgb, cv::COLOR_BGR2RGB);
            emit frameReady(QImage(rgb.data, rgb.cols, rgb.rows,
                                   rgb.step, QImage::Format_RGB888).copy());
            // m_mode 에 따라 분석 …
        }
    }
private:
    std::atomic<bool> m_stop{false};
    std::atomic<int>  m_mode{0};
};

// 메인 스레드
connect(cam, &WebCamThread::frameReady, this, [this](const QImage &i){
    pCamView->setPixmap(QPixmap::fromImage(i));   // 메인 스레드에서만
});
// 종료: cam->requestStop(); cam->wait();
